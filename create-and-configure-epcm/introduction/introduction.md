# Introduction

## About this Workshop

This workshop is a step-by-step guide to creating and configuring an Oracle Enterprise Profitability and Cost Management (EPCM) application in Oracle Fusion Cloud Enterprise Performance Management (EPM). Through hands-on labs you will enable the EPCM business process, build an application both from scratch and by migrating an existing Profitability and Cost Management (PCM) application, model cost allocations by creating allocation and custom calculation rules, edit rules in bulk, and use the built-in PCM Agent (Generative AI) to drive modeling tasks with natural language.

Key tips, design considerations, and best practices are included throughout to help you avoid common pitfalls and implement effectively.

Estimated Workshop Time: -- hours -- minutes

### Objectives

In this workshop, you will learn how to:

* Enable an Oracle Cloud EPM environment as an Enterprise Profitability and Cost Management business process
* Create and configure an EPCM application from scratch
* Migrate an existing Profitability and Cost Management (PCM) application to EPCM
* Create a model and rule set
* Create an allocation rule (source, destination, driver basis, offset)
* Create a custom calculation rule
* Edit rules in bulk on the Mass Edit page
* Automate modeling tasks with the PCM Agent using Generative AI

### Prerequisites

This workshop assumes you have:

* A working understanding of Oracle Enterprise Performance Management (EPM) Cloud
* An **EPM Enterprise Cloud Service** subscription
* **Service Administrator** access to the EPM Cloud environment(s) used in the labs
* Basic knowledge of the Cloud EPM platform (navigation flows, File Explorer, jobs)
* Knowledge of Profitability and Cost Management (optional, but useful for the migration lab)

> **Note:** Some labs use two separate EPM Cloud environments &mdash; one with a Profitability and Cost Management application to migrate *from*, and a second, empty environment on which the EPCM business process is created. The migration lab explains this requirement in detail.
